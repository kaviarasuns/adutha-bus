# Fieldwork checklists

One CSV per route variant between Coimbatore Gandhipuram and Tiruppur Old Bus Stand:

| File | Route |
| --- | --- |
| `stops-avn.csv` | via Avinashi |
| `stops-pld.csv` | via Palladam |
| `stops-smn.csv` | via Somanur (unconfirmed variant) |

Each row is a named OpenStreetMap bus stop within 45 m of the road, in order from Gandhipuram, with its distance along the road. While riding the route, fill in:

- `buses_stop_here_yes_no`: whether corridor buses actually stop there.
- `correct_name`, `correct_tamil_name`: the name on the board or the one conductors call out, if it differs.
- `notes`: anything else, and add rows for stops that are missing. OpenStreetMap has few stops on the highway stretches.

The pre-filled columns are © OpenStreetMap contributors, under the [ODbL](https://opendatacommons.org/licenses/odbl/).
